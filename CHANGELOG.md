# Changelog

## 0.4.2 — Review Hardening: Unlimited Quota Display, Admin Validation & Supabase RLS/Persistence Fixes (2026-11-25)
- **Entitlement Quota Formatting (`∞` / `0`)**: Added `formatQuotaLimit` in `src/lib/entitlements/helpers.ts` and fixed `CustomerDashboard`, `SavedProfilesModule`, `ProfileHeadquarters`, and `PricingExperience` so unlimited (`enabled: true, numericLimit: null`) limits display `∞` instead of `/ 1`, `0`, or literal `null`, and disabled features with `numericLimit: null` display `0` instead of `∞`.
- **Admin Entitlement Editor Hardening**: Rejected blank quota input (`""`) in `AdminConsole.tsx` (previously parsed as `0` and silently disabled features), fixed boolean-feature detection across all plans so quota edits on Agency aren't wiped on toggle, added in-flight double-submit guard, and added server-side `.max(100_000)` validation in `/api/admin/actions`.
- **Supabase Postgres RLS & Persistence Fixes**:
  - Updated `src/lib/dashboard/store.ts` to upsert `workspace_members` rows on workspace creation (matching RLS `is_workspace_member()`), write `profile_snapshots` with admin/service client fallback (matching migration 2 RLS) and read `data_class` back, persist comparison `description` and `notes` to `comparison_projects` (aligned with `competitor_sets`) without empty `{}` updates, validate UUIDs on `folder_id`, lowercase usernames, and resolve target workspaces by name.
  - Updated `src/lib/admin/store.ts` to sanitize UUIDs on `updated_by`/`created_by`/`user_id` and return `null` on DB write failure for support tickets & broadcasts instead of silently falling back to local JSON.
  - Added `loadAdminUsers`, `loadAdminUserById`, and `persistAdminUserUpdate` in `src/lib/auth/session.ts` wired into Admin pages and `/api/admin/*` routes.
  - Wired async DB-aware helpers into `/api/search` (`loadIsFeatureFlagEnabled`), `/api/billing/checkout` (`persistFunnelEvent`), `/api/auth/export-data` (`loadUserEntitlementOverrides`), and prevented `audit_logs.actor_id` FK violation on self-deletion in `/api/auth/delete-account`.
- **Localization & Mobile Verification**: Localized `ProfileHeadquarters` `member-since` date formatting and `ToolsDirectoryClient` localized category search; expanded Vitest to 53/53 passing tests and verified German/French `375px` mobile layouts in headless Chrome E2E.
